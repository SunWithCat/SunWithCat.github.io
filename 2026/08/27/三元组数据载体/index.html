Dart 3 Records 元组与模式匹配实战

发表于2026-08-27|更新于2026-08-27|Flutter
|总字数:849|阅读时长:3分钟|浏览量:

在日常开发中，有时一个方法需要返回多个不同类型的值。在 Dart 3 之前，我们通常需要专门新建一个数据类（Data Class）或返回 Map / List，不仅繁琐还容易丢失类型安全。

从 Dart 3 开始，官方正式引入了 Records（记录/元组） 和 Patterns（模式匹配），极大地提升了多返回值处理与类型过滤的效率。

1. Records（元组）作为轻量数据载体

当方法只需在局部承载多类型数据时，使用元组无需额外定义类。

💡 注意点：
千万不要写成 if (data[i] case String)！在 Dart 模式匹配中，case String 会被识别为常量匹配（即比较对象是否等于 Type 类型的 String 本身）。如果要进行类型过滤，必须写作 case String name（绑定变量）或 case String _（通配符）。

  • Records：告别为了几个简单返回值就写一个临时类的繁琐，配合命名参数与解构语法，既轻量又类型安全。
  • Patterns (if-case / switch)：告别繁重的 is + 强制类型转换，模式匹配能在判断结构的同时完成解构和智能类型提升。
